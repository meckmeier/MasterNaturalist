## Organization Management
<details>
<summary>How do I enroll an organization in WildPathsWI.org?</summary>
Use the Add Organization menu option. Fill out the form. You will get an email once the enrollment request is approved. The email will have a link to create a login, if you don't already have one. Use that link. If you already have a login then return to WildPaths and login - you will see a new Manage Organization button on the main page, and a new Organizer menu on the main menu list. On the tuturials page there is a video that will take you through the process of enrolling your organization.
</details>
<details>
<summary>I've enrolled my organization - what do I do now?</summary>
You should receive an email with an invitation to create a username. Follow the instructions and create a username. It's important to use that link so that your new username is 'connected' to the new organization. Although if you already have a login name when you did the Add Organization, you won't get that email. Your username is already 'connected'. With your connected username, a new menu item (Oganizer) will appear on the hamburger menu and a new button on the main landing page: Manage Organizations. This is the page you will use to add Activities, Locations, and Other Managers. There is a tutorial video that will take you thru the steps of using the Manage Organization page.
</details>
<details>
<summary>What is the difference between the MAP page and the little Region Map?</summary>
The MAP page (you get there by clicking MAP on the main landing page) will take all locations with valid addresses and put a flag on the map for them. The default is that the map only shows if your location has activities. You can change that by using the Filter button to select Show all Locations. The Region map though just shows quickly what general region your organization is in (you select this when creating your organization). For locations, when you create the location, the system will select the location when you type in a zip code. Then all activities that take place at that location will display the Region map.
</details>
<details>
<summary>How do I know what Region my organization is in?</summary>
Regions are defined by counties - there is a Region by County page from the Tutorials page, where you can see which region your county is in.
</details>
<details>
<summary>How do I get a flag on the big map?</summary>
You need to create a location in the Org Management page - and put in the address with zip code. There is a routine that is run (usually daily) that will find the latitude and longitude values for that address. This is what is needed to for the map to create a flag.
</details>
<details>
<summary>I really only have one location - can I make it so that all my activities are on that location?</summary>
Absolutely. Go go the Org Management page, and find the pencil icon next to your Organization name. From there, near the bottom of the page, you will find DEFAULT location button. Click it and select your location... Of course you have to have already created the location first.
</details>
<details>
<summary>I created a location when I added my first activity - Why doesn't it show up on the map?</summary>
The Activity page has a quick add feature, so you can create the location NAME when you add in an activity. This is to help you speed up the process. Once it's created you can reuse it for multiple other activities. But to get the flag, you need to find the pencil icon next to your location name in the Organization Management page to type in the actual address. And the routine that find the longitude and latitude (needed to map the location) runs usually daily.
</details>
<details>
<summary>I already know my latitude and longitude. Can I just type it in the system?</summary>
That field is not visible right now, but it will appear in future editions of the app.
</details>
<details>
<summary>Why are there two different URLS in the activity page - one at the top and one in the session section?</summary>
The URL at the top (activity URL) is used for the MORE information link. Any activity could have a page in your own web site with more information on this activity. The one in the session section is for ONLINE activities and it should be the link for registering for the session, or viewing the online session. 
</details>
<details>
<summary>Can you explain what the session format?</summary>
When you are adding sessions for your activity, you can say WHERE it happens - which could be a physical location or a website/online feature. You can have events that have both components (I'm thinking of seminars that might be in person, but an accompanying zoom meeting might be scheduled too.). If this is a volunteer activity and the person can do it from any property they want (thinking of say a birdfeeder bird count), then the activity would be at a self-selected location.
</details>
<details>
<summary>Can you explain what the ongoing checkbox means?</summary>
When you are adding sessions for your activity, you can say WHEN it happens. Usually this will be a fixed date. For those events, you would leave the ongoing checkbox unchecked. But if the event can happen at your own convenience - say an online course, or a birdfeeder bird count - then it would be ongoing. When you check ongoing though, you will get a start and end -- this is to set the time frame over which this particular event will be active. Some have no specific dates, but if you want the event to roll off outside a date range, then you can put in a start and end date.
</details>
<details>
<summary>Why can't I do recurring events?</summary>
In the interest of making the site easy to build and easy to navigate, I didn't build a full on calendar function. So if your event is recurring, you have to type in each date as a session. Any event that is not ongoing will appear on the calendar on the dates that you add. If you want it to appear multiple times on the calendar you have to create multiple sessions.
</details>
